# Notchy 测试

## 自动测试

从项目根目录运行：

```bash
bash tests/run-tests.sh
```

测试只依赖 Node.js 内置的 `node:test`，不需要安装 npm 包。脚本会直接提取当前 QML 文件中的函数进行隔离验证，并检查：

- 番茄钟绝对时间计时、暂停恢复、自然完成、手动跳过和 IPC 分发；
- Kimi / DeepSeek 响应解析、请求去重、取消、超时状态与错误分支；
- 暂存架去重、30 项上限、删除和清空；
- 六标签页共享模型与组件引用；
- 日历下一日程选择和单次临近提醒；
- 活动 QML 文件结构、本地类型、JavaScript 导入和插件清单入口。

如果系统存在 `qmllint`，脚本会继续检查全部活动 QML 文件；未安装时会明确输出 `SKIP`。Node 隔离测试不能替代 Quickshell/DMS 的实机类型检查与交互验证。

## 人工回归清单

### 启动与药丸

- [ ] `dms restart` 后顶栏药丸正常显示，日志没有 Notchy QML 错误。
- [ ] 无媒体时显示日期时间；播放媒体时显示曲名和频谱；番茄钟运行时优先显示倒计时。
- [ ] 调整音量、静音和取消静音各只闪现一次，初次启动不同步闪现旧音量。
- [ ] 新通知、日程临近和文件暂存提示仍能正常闪现。

### 六标签页与 IPC

- [ ] 弹层显示媒体、通知、剪贴板、暂存架、专注、用量六页，页面内容与标签一致。
- [ ] 通知和暂存架徽标出现在正确标签上。
- [ ] 右键菜单显示六个直达图标，包括“用量”，点击后打开对应页面。
- [ ] `openTab usage`、`openTab media` 等命令打开正确页面，`close` 能关闭弹层。

### 番茄钟

- [ ] 开始、暂停、继续和重置正常，暂停期间剩余时间不变化。
- [ ] 手动跳过工作阶段进入休息，不通知且不增加完成轮数；跳过休息回到空闲。
- [ ] 空闲状态执行 `pomo skip` 不会启动休息。
- [ ] 自然完成工作和休息仍发送通知，工作自然完成计入轮数。

### 弹层与监控

- [ ] 悬停弹层会 transient 展示，点击药丸可固定；Esc 和点击外部可关闭。
- [ ] 弹层仍居中于顶栏，不出现左上角偏移。
- [ ] 底部监控条在弹层可见时更新，展开后显示各核 CPU、内存和 Top 3 进程；关闭弹层后详情收起。

### 暂存架与 Wayland 拖拽

- [ ] 拖文件到药丸和暂存架页面都能加入，重复文件不会重复计数，重启后列表保留。
- [ ] 从暂存架整行拖到其他应用时，弹层不会因 hover 关闭而销毁，也不发生崩溃。
- [ ] 拖出会话能离开 DMS 自身窗口；单击打开、复制路径、单删和清空正常。

### 用量与日历

- [ ] 首次查询显示加载状态而非“未配置 Key”，已有数据刷新时保留内容并显示“刷新中…”。
- [ ] 手动刷新、切页刷新和 Key 更新正常；网络错误、认证错误和超时提示可区分。
- [ ] 媒体页显示最近的非全天未来日程，临近 15 分钟只闪现一次。
